# Kaggle Datasets Analysis

## Project Overview

This project analyzes Kaggle datasets using Python and data visualization techniques.

## Features

* Dataset exploration
* Top downloaded datasets analysis
* Dataset popularity insights
* Data visualization using Matplotlib

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## How to Run

1. Install requirements:
   pip install -r requirements.txt

2. Run:
   python kaggle_analysis.py

## Dataset

all_kaggle_datasets.csv
